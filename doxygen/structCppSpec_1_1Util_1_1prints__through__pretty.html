Detailed Description

template<typename T>
struct CppSpec::Util::prints_through_pretty< T >

Whether T prints differently through Pretty than through operator<<, so a container holding it is printed element by element through Pretty.

True for a bool, a byte-sized integer, a wide character, a C string, a pointer to other characters, an enum with no operator<< and an optional, and for a pair, a tuple, a standard container, a built-in array or a range with no operator<< of its own that holds one of these, however deeply. A range type with its own operator<< prints through it.
