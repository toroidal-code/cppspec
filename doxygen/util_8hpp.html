◆ string_view_of()

template<Util::is_string_like T>
std::optional< std::string_view > CppSpec::string_view_of ( const T & text)
nodiscardconstexpr

View text as a std::string_view, the one form the string matchers and the printer compare and print.

A char array passed here itself is read up to its first NUL and no further than its end. A char array given to expect() or to a matcher has already decayed to a pointer by the time it is viewed, so it is read as a C string, up to its first NUL, and must be NUL-terminated; wrap a fixed-size buffer in std::string_view(buffer, size).

A null C string is no text at all: it equals only another null C string, the matchers that search text fail on it, negated or not, whether it is the actual value or the text looked for, and it prints as nullptr.

A temporary std::string is refused, because the view would outlive its text.

Parameters
texta std::string, std::string_view, char array or char pointer
Returns
a view of the text, or std::nullopt for a null C string

◆ strip_type_keywords()

std::string CppSpec::Util::strip_type_keywords ( std::string_view name)
inline

Removes the enum , class , struct and union keywords MSVC writes before every type in a type name.

MSVC names std::vector<Colour> as class std::vector<enum Colour,class std::allocator<enum Colour> >; without the keywords it reads std::vector<Colour,std::allocator<Colour> >. A keyword is removed only where it starts a word, so a name such as my_class Foo is kept whole.

Parameters
namea type name
Returns
the name without the keywords
